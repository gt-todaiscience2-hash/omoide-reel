# おもいでリール

写真を選ぶだけで、雰囲気に合ったBGMつきのスライドショーを自動でつくるWebサイトです。
学園祭・旅行・サークルの写真を、動画やポスターにしてLINEでそのままシェアできます。

## 使い方（おすのは2回）

1. **「写真を選ぶ」** → 選んだ瞬間に、BGMつき動画が始まります
2. 見ている間に動画ができあがるので、**「LINEに送る」** をおして送り先をえらぶ

最初の画面で押すのは「写真を選ぶ」ボタン1つだけ。曲・かたち・はやさ・ならび順は全部おまかせで決まります。
変えたいときだけ「編集」を開くと、ボタンを選ぶだけで変えられます（変えるとすぐ最初から流れます）。

## 中高生が、教わらずに使えるように

- **大きい青いボタンは、どの場面でも1つ**：それを押していけば最後まで行けます
- **ボタンの名前＝押すと起きること**：「動画を作る（14秒）」→「動画を作っています あと13秒」→（止めたら）「続きから作る」→「LINEに送る」。同じ場所の同じボタンが、そのときの状態に合わせて名前を変えます
- **LINEの中で開いたとき**：最初の画面で「Safari / Chrome で開く」を主ボタンとして出し、「写真を選ぶ」は控えめなボタンに下げます。写真を選ぶ前にふつうのブラウザへ移れるので、最後に送れなくなる失敗を防ぎます
- **iPhoneの共有画面**：できあがると「LINEがないときは、右端の『その他』から」と出ます（送ると消えます）
- **慣れた場所に、慣れたボタン**：音のオン・オフは動画の右下、止めた写真を外す「この写真を外す」ボタン（ゴミ箱の絵つき）は右上、戻るは左上
- **写真の帯**：動画の下に写真が並び、押すとその場面に飛びます
- **編集はタブ式**：曲／タイトル／写真／形・速さ。閉じるのは下の「閉じる」ボタン1つ（シートを下に引いても閉じます）
- **表紙**：1枚目が表紙で、タイトルが乗ります。写真タブの「表紙にする」で、1回で入れかえられます
- **写真の見せ方**：「アップで動かす」（標準）か「余白あり（全部映す）」
- **雑に触ってもこわれない**：動画を何度止めても作りかけの動画は捨てません。早すぎる「送る」も連打も、戻るジェスチャーも大丈夫です
- **打たなくていい**：タイトルは「2026年11月」「文化祭」「体育祭」「修学旅行」「部活」などを押すだけ
- **パソコン・Chromebook**：ドラッグ、貼り付け、Space（再生・停止）、← →（前後の写真）、M（音）、Delete（今の写真を外す）

- 最初の画面は、上から「空色 → ミント → 地の色」のやわらかいグラデーション（ダークモードでは暗い色）。写真が主役の動画の画面は単色のまま

### 小さい子に使わせるとき（ふりがな表示）

最初の画面のいちばん下「ふりがなをつける」を押すと、画面の漢字すべてにふりがなが付きます。
URLの最後に `?kana=1` を付けたリンクを渡せば、最初からふりがな表示で開きます。

| タブレット縦 768×1024 | 上から80%・高さ76px | 上から94%・高さ76px | 688×387 |
| タブレット横 1024×768 | 上から77%・高さ76px | 右下 | 615×345 |

「最初に戻る」は左上の端にあり、押すと確認が**画面の下**（指の届く場所）に出ます。

| 編集のタブ | 選べるもの |
| --- | --- |
| 曲 | はずむ / なつかしい / さわやか / 夜 / 曲なし（写真の雰囲気に合うものに「おすすめ」印） |
| かざり | **色あい**（動画全体）：そのまま / ふんわり / フィルム / 思い出 / 白黒 / 夏。いま映っている写真で見本を表示。**おまかせでかざる**：写真の雰囲気から3枚に1枚くらいにスタンプ、いちばん明るい1枚に動くかざり（「全部外す」で戻せる）。タブの中は「スタンプ / 動き / ひとこと / 色あい」の切りかえ式（付いているものには青い点）。**この写真に**（◀▶で写真を切りかえ）：スタンプ12種（最初は左下。同じスタンプをもう一度押すと右下→右上→左上）、動くかざり（ハート / キラキラ / 花びら）、ひとこと（16文字まで・候補あり） |
| タイトル | 「2026年11月」「文化祭」などの候補を押すか、自分で入力。表紙（1枚目）に重ねて表示 |
| 写真 | 写真を押すとその場面へ。◀▶で入れかえ、右上の✕で外す。「表紙にする」で1枚目に（いまの表紙は「★ 表紙」）。一覧の最後の「＋ 写真を追加」、写真を1枚にまとめた画像（コラージュ）づくりもここ |
| 形・速さ | 形：横 / 縦 / 正方形（写真の向きに合うものに「おすすめ」印）。速さ：おまかせ（全体がおよそ50秒以内）/ さくさく（短め）/ ゆったり（長め）。写真の見せ方：アップで動かす / 余白あり（全部映す） |

### かざりのしくみ

- 描く順番は「写真 → 色あい → 重ねる効果（周辺を暗く・やわらかい光・フィルムの粒）→ 動くかざり → スタンプ → ひとこと → タイトル」。画面に描いたものがそのまま動画に入ります。
- 色あいは、iPhoneのSafariが canvas の `filter` に対応していないため、写真の色を変換表で1回だけ塗り替えています（前後数枚ぶんだけ。帯に分けて少しずつ処理するので再生がカクつかない）。
- スタンプ・動くかざりの絵はすべてコードの中で線と色から描いたオリジナルで、外部の画像や絵文字フォントは使いません（どの端末でも同じ見た目）。
- スタンプは写真が出て0.3秒後にポンと出て、かすかにゆれ、次の写真と一緒に消えます。止めているときは出きった状態で見せます。
- 動くかざりの動きは写真ごとに決まった値で作るので、再生と動画で同じ動きになります。
- かざりを付けると、その写真の場面だけを再生して見せて止まります（このときは動画を作りません）。
- 何も選ばなければ「そのまま・かざりなし」。勝手には付きません。
- 高さの低いスマホ（iPhone SE など、画面の高さ700px以下の縦向き）で編集しているあいだは、上の帯と送るボタンをいったん隠して編集の欄を広くし、スタンプは2段の横スクロールにします。「閉じる」でもとに戻ります（320×568でも、スクロールなしでスタンプが7個見える）。

### 知っていると便利な操作

- 動画を**左右にスワイプ**すると前後の写真へ（パソコンは ← → キー）。再生バーは写真の頭にぴったり止まり、「3/12枚目」と出ます
- アレンジの「ならび順」で写真を押すと、その場面に飛びます。× で外した写真は、直後なら「元にもどす」で戻せます
- 同じ写真を二重にえらんでも、1枚にまとめます
- 読み込みが長いときは「ここまでの写真でつくる」で切り上げられます
- スマホを横にすると、左に動画・右に操作の2列になります
- 写真が入っている間は、うっかり更新・戻るをしても確認が出ます
- 保存した動画のファイル名には、タイトルが入ります

### 画面の配置の考え方

スマホを片手で持って使うことを前提に、**見るものは上、押すものは下**に分けています。

- いちばん押す「写真をえらぶ」「LINEに送る」は、親指が自然に届く画面の下側に、幅いっぱいで置いています（右手でも左手でも同じ）
- 「アレンジ」は下からせり上がるシート。上の動画を見ながら、下で指を動かすだけで変えられます
- 取り消しにくい「写真をえらび直す」は、押しまちがえにくい左上に置き、2回押して初めて実行されます
- 押せるものはすべて高さ44px以上、となり同士は8px以上あけています
- 再生バーのつまみは指でつかみやすい大きさにしています
- 端末がダークモードのときは、暗い配色に切りかわります

パソコンでは共有ボタンがないため、「LINEに送る」のかわりに「動画を保存」と表示されます（写真はドラッグ＆ドロップでも入れられます）。

## LINEグループでの使い方

公開したURLの最後に `?openExternalBrowser=1` をつけて、グループのトークやノートに貼っておくのがおすすめです。

```
https://（ユーザー名）.github.io/omoide-reel/?openExternalBrowser=1
```

こうすると、タップしたときにLINEの中のブラウザではなく Safari / Chrome で開くので、「LINEに送る」ボタンがそのまま使えます。

```

https://（ユーザー名）.github.io/omoide-reel/?openExternalBrowser=1
```

### Androidなら、写真えらびも省けます

Chromeでこのサイトを開き、メニューの「ホーム画面に追加」をしておくと、LINEで写真をえらんで
「共有」→「おもいでリール」で、写真が入った状態で開きます（iPhoneはこの仕組みに対応していません）。

### LINEの中だけで完結できないの？

LINEのトーク画面の中だけで動かすには「LINE Bot（公式アカウント）」と、写真を受け取って動画を作るサーバーが必要です。
その場合、写真をサーバーに預けることになり、サーバーの運用・費用・管理責任も発生します。
このサイトは「写真をどこにも送らない」ことを優先して、ブラウザだけで動く形にしています。

## 公開したら、スマホで最初に確かめること

パソコン上の自動テストでは確かめられない3つです。

1. **iPhoneのSafariで作った動画の音**：動画を作って、LINEの「Keepメモ」（自分だけのトーク）に送り、音が出るか・音と映像がずれないかを見る
2. **LINEからブラウザへの移動**：グループLINEに貼ったリンクをタップし、iPhone・AndroidそれぞれでSafari / Chromeに移るか。LINEの中で開いたときの「Safari / Chrome で開く」ボタンも押してみる
3. **たくさんの写真**：iPhoneのカメラ写真（約4000×3000）を60枚まとめて選び、読み込みの途中でページが落ちないか

## GitHub Pages で公開する手順（コマンド不要）

1. GitHub にログインし、右上の「＋」→「New repository」。名前（例：`omoide-reel`）を入れ、**Public** を選んで「Create repository」。
2. できたページの「uploading an existing file」をクリック。
3. このフォルダの**中身すべて**（`index.html`、`sw.js`、`manifest.webmanifest`、`css`・`js`・`audio`・`icons` フォルダなど）をドラッグ＆ドロップし、「Commit changes」。
4. リポジトリの「Settings」→ 左の「Pages」→ Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして「Save」。
5. 1〜2分待つと `https://（ユーザー名）.github.io/omoide-reel/` で公開されます。

※ `index.html` をダブルクリックして開くだけではBGMが鳴りません（ブラウザの安全上の制限）。公開したURLで開いてください。
※ ファイルだけの静的サイトなので、Firebase Hosting など他の静的ホスティングにもそのまま置けます。

## 対応ブラウザ

Chrome / Edge / Safari の新しい版。動画の形式はブラウザによって変わります。

| ブラウザ | できる動画 |
| --- | --- |
| Windows・Mac・Android の Chrome / Edge、iPhone・Mac の Safari | MP4（H.264 + AAC）— LINEでそのまま再生 |
| Linux の Chrome など | MP4（H.264 + Opus）または WebM |

## BGMを差し替えたいとき

`audio/` の4つのMP3を同じファイル名で置き換えるだけです。自分で使用許諾を確認したフリー音源を使ってください。

## ファイル構成

```
index.html             画面
css/style.css          見た目
js/app.js              すべての処理（外部ライブラリなし）
audio/*.mp3            オリジナルBGM 4曲
sw.js                  他アプリの「共有」から写真を受け取る係（Android・ホーム画面に追加した場合のみ働く）
manifest.webmanifest   ホーム画面に追加するための設定
icons/ , favicon.svg   アイコン
tools/make-bgm.py BGMを生成したスクリプト（サイトの動作には不要）
```
